# 👜 BagsByMeer

> *Handmade with love and perfection in Nepal.*

**BagsByMeer** is a modern, responsive, and fully interactive e-commerce web application built for a handmade artisan bag brand based in Nepal. It features a curated product catalog, shopping cart drawer, category filters, and a **cloud-synced database admin panel** powered by Firebase.

---

## ✨ Key Features

- **Artisanal E-Commerce UI:** Warm, elegant design styled with Tailwind CSS, custom typography, and smooth transitions.
- **Dynamic Cloud Database (Firebase Firestore):** Real-time inventory sync for bag collections, prices, descriptions, and categories.
- **Built-In Admin Dashboard:** Click the top-right **Admin** lock button on the live site to securely add new bags, edit prices, update images, and delete items.
- **Stock Management:** Toggle items between *"In Stock"* and *"Out of Stock"* (automatically applies grayscale filter, warning badge, and disables purchasing).
- **Made in Nepal & Contact Info:** Integrated direct phone contact (`+977 9861585576`), Instagram, and TikTok links.
- **Lightning-Fast Deployment:** Hosted seamlessly via Cloudflare Pages and GitHub.
